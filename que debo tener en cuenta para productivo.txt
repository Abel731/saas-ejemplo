💡 ¿Qué son realmente Supabase y Vercel?
Supabase es como una planilla de Excel gigante en la nube:
En vez de guardar los precios y fotos en tu computadora, los guardás en una planilla en internet. Tu página web lee esa planilla y 
muestra las hamburguesas.

Vercel es como una carpeta pública en internet:
En vez de tener tu archivo tioslandingpage.html guardado en tu carpeta de Descargas, lo arrastrás a Vercel. 
Vercel te da un enlace (link) y listo: cualquier persona en el mundo que toque ese link puede ver tu página desde su celular.

🚀 Paso a Paso: Preparando todo para el 01/08
Para que no te compliques con código técnico raro, te dejé todo preparado para que sea casi un trabajo de copiar, pegar y hacer clics.

Paso 1: Crear tu planilla en Supabase (Base de datos)
Entrá a Supabase.com y creá una cuenta gratis.

Hacé clic en "New Project" (Nuevo Proyecto), ponele de nombre tios-food-garden y creá una contraseña.

En el menú de la izquierda, buscá el ícono del SQL Editor (parece un par de tablas o un símbolo de consola).

Hacé clic en "New Query", pegá este código tal cual está abajo y hacé clic en el botón verde "Run":

SQL
-- 1. Creamos el local de Tío's Food Garden
CREATE TABLE restaurants (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    name VARCHAR(100) NOT NULL,
    slug VARCHAR(100) UNIQUE NOT NULL,
    phone_whatsapp VARCHAR(20) NOT NULL,
    is_active BOOLEAN DEFAULT TRUE
);

-- 2. Creamos la tabla de productos
CREATE TABLE products (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    restaurant_id UUID REFERENCES restaurants(id) ON DELETE CASCADE,
    name VARCHAR(100) NOT NULL,
    description TEXT,
    price DECIMAL(12, 0) NOT NULL,
    image_url TEXT,
    is_available BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

Paso 2: Subir tu página a Internet con Vercel
Entrá a Vercel.com y registrate gratis (podés usar tu cuenta de Google).

En tu pantalla principal vas a ver una opción que dice "Deploy" o un recuadro para arrastrar archivos.

Arrastrá la carpeta de tu computadora (pruebasirgp) y soltala ahí.

En 10 segundos, Vercel va a procesar todo y te va a dar un link público del estilo: [https://pruebasirgp.vercel.app](https://pruebasirgp.vercel.app).

¡Ese link ya lo podés abrir desde cualquier celular, compartir por WhatsApp o convertirlo en un código QR para poner en las mesas!
